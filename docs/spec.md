# Astro-Notepad 仕様メモ

Astro製ブログ向けのシンプルなエディタ。MITライセンスで公開する。

## 決まったこと

### 対象と配布

- 対応OSはAndroidとLinux(Kubuntu)。Linuxはバイナリを実行して使う
- ブランチ管理はGit-Flow

### 範囲

- Git関連の機能はMVPに含めない
- Astroのプレビューは入れない。カスタムCSSも読み込まない
- 画像の管理画面はいったん作らない

### 記事の保存と書き出し

- 記事のディレクトリ名をslugとして使う
- 出力の形は以下。リポジトリの直下に重ねれば取り込める

  ```
  ./{slug}/src/content/posts/{slug}.md
  ./{slug}/src/assets/{slug}/
  ```

- Linuxは実行ファイルの場所に上の形で書き出す。リポジトリへ直接書き込む機能は付けない
- Androidは書き出し機能(zip)を付ける

### フロントマター

ユーザーにフロントマターを書かせない。

- title: 左上のH1。書き換えるとそのまま反映する
- description: タイトルの下に置く

### 画面

- 記事一覧はサイドバーに置く。デスクトップでも折りたためるようにする(おおむねSCITLと同じ)
- 編集画面はタイトル(H1)、説明、本文の順に並べる
- 設定画面は置く。今のところ中身はライセンスの表示だけ

### 見た目

基本はSCITL(`~/Documents/SCITL-2.0`)にならう。

- Markdownのレンダリングは最小限にする。記号は消さず、スタイルと画像の表示だけを付ける
- フラットデザインにする。SCITLの塗りの段差や影は使わず、文字と最低限の仕切り線で表す
- 色は白(HSV(0,0,98))と黒(HSV(0,0,0))を基本に、灰色と淡いアクセント色を使う。灰色は仮に明度50%とする
- 書体

  | 箇所 | 書体 | ウェイト |
  |---|---|---|
  | 見出し・太字 | Noto Sans JP | 500 |
  | 画面の文字(ボタン・メニューなど) | Noto Sans JP | 400 |
  | 上記以外(本文など) | Noto Serif JP | 400 |

- アイコンはGoogleのMaterial Symbols

## 未定のこと

### 技術選定

- 案はSCITLと同じTauri 2 + React + Vite + TypeScript。編集欄はCodeMirror 6。SCITLの書き出し処理(Androidのzip)、トークン、アイコン、フォント、ビルド用スクリプトを流用できる
- WebViewからの外部通信の止め方。案は、CSPで通信先を自分のアプリ内に限り、本文中の外部画像は読み込まず、生のHTMLは描画しない

### 範囲

- Git関連の機能を積むか。積むなら外部通信のリスクをどう抑えるか
- 既存の記事を読み込んで編集できるようにするか。Git関連の検討結果による
- slugをディレクトリ名から取る方式は、Gitからpullする仕組みを入れた場合に見直しが要るかもしれない
- Astroに寄せない、ふつうのMarkdownのプレビューを置くか
- 画像管理の画面が無い間、本文の画像をどうやって`src/assets/{slug}/`に入れるか
